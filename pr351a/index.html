Portfolio

Work

This collection highlights work in interviewing, public relations writing, media analysis, website design, and visual storytelling.

Project 01

Partner Profile

A profile of Oliver Rahnama based on a class interview and partner meeting.

For this project, I interviewed classmate Oliver Rahnama and developed a written profile from our conversation. The assignment strengthened my ability to prepare questions, listen for useful details, and shape interview material into a clear story.

Skills: Interviewing, note-taking, profile writing, editing

Project 02

PESO Analysis

An analysis of the NBA 2K27 cover as owned media, with ideas for paid, shared, and earned extensions.

I examined the NBA 2K27 cover and identified it as owned media because the publisher controls the message and the channel. I also considered how the same campaign could expand through paid placements, shared social content, and earned media coverage.

Skills: PESO model, media classification, audience strategy, concise explanation

Project 03

Website Design Analysis

A comparison of Apple, Arngren, and YouTube through hierarchy, alignment, proximity, repetition, contrast, and simplicity.

I compared Apple, Arngren, and YouTube using hierarchy, alignment, proximity, repetition, contrast, and simplicity. The review showed how visual systems guide attention, organize information, and affect usability.

Skills: Visual analysis, web design principles, comparative writing

Project 04

E-Waste Infographic

A visual story about global electronic waste growth, recycling rates, and one practical action people can take.

I created a visual story showing that global e-waste is growing much faster than documented formal recycling. The design turns a large data gap into a clear message and ends with a practical call to action: find a local authorized e-waste drop-off.

Skills: Data storytelling, information design, visual hierarchy, source attribution
